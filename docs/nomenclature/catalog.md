# Catálogo de nomes — versão 1

Padrão público: `EPA <NOME>`. Identificadores técnicos em minúsculas com hífen.

| Nome oficial | Identificador | Responsabilidade |
| --- | --- | --- |
| EPA SENTINEL | `epa-sentinel` | Políticas, verificação e isolamento da cadeia científica |
| EPA GENESIS | `epa-genesis` | Geração longitudinal de dados sintéticos |
| EPA ATLAS | `epa-atlas` | Registro curricular baseado em referências oficiais |
| EPA CORE ENGINE | `epa-core-engine` | Preparação, treinamento e avaliação dos modelos |
| EPA LEDGER | `epa-ledger` | Evidências, proveniência, histórico e auditoria |

O nome ERIL é histórico. Sentinel e Ledger são responsabilidades distintas: **Sentinel decide**, **Ledger registra**. Nenhum dos cinco nomes exige microsserviço dedicado no MVP.
