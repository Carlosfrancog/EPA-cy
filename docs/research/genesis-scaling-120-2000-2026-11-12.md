# GENESIS Rust — campanha de escalabilidade 120–2.000 estudantes (2026-11-12)

## Fonte e status da evidência

Transcrição das saídas de console fornecidas pelo operador após integração do caminho nativo sem round-trip JSONL (PR #55). A campanha de 120 estudantes está descrita também em `genesis-direct-records-first-120-results.md`. **Não é uma execução CI ou reprodução independente.** Os arquivos `benchmark.json` originais permanecem no ambiente Windows local; **não foram anexados nesta etapa**, portanto o tamanho em bytes dos Parquet e os metadados completos não foram verificados para os três novos volumes.

Comando por campanha:

```powershell
python tools/benchmark_genesis.py --students N --seed 20261029 --warmups 1 --repeats 5 --engines python_v3_pyarrow rust_native_parquet
```

`N ∈ {120, 500, 1000, 2000}`. O catálogo é `examples/atlas.demo.json`; cada teste inclui uma rodada de aquecimento e cinco rodadas medidas, compilação Rust release concluída antes de iniciar a medição. Ordem dos motores fixa: Python v3, Rust nativo. As métricas de tempo incluem inicialização do processo e geração/persistência; excluem validação de paridade e compilação. Memória é RSS amostrado, não pico garantido. Campanhas 500/1000/2000 registraram `PASS` na comparação `EXCEPT ALL` para todas as entidades em todas as rodadas.

## Comparações derivadas

`speedup(N) = mediana(Python v3, N) / mediana(Rust nativo, N)`.

| Estudantes | Fator de aceleração Rust/Python | RSS Rust observado no console | RSS Python observado no console |
|---:|---:|---|---|
| 120 | 5,47× | aproximadamente 17,9–18,1 MiB | aproximadamente 89,7–90,2 MiB |
| 500 | 3,78× | aproximadamente 20,5–21,7 MiB | aproximadamente 92,8–93,2 MiB |
| 1000 | 3,44× | aproximadamente 22,3–23,3 MiB | aproximadamente 93,7–94,2 MiB |
| 2000 | 3,10× | aproximadamente 24,3–25,0 MiB | aproximadamente 95,5–98,3 MiB |

A vantagem relativa decresce conforme o volume aumenta (5,47× → 3,10×). **Hipótese**, ainda não verificada via profiler: a inicialização do Python tem peso proporcionalmente maior nos volumes pequenos; custos de I/O e geração passam a dominar volumes maiores. Não afirmar causalidade apenas a partir de tempos totais.

O Rust apresenta crescimento de tempo próximo do linear para os volumes analisados, sem permitir extrapolação ilimitada: `students` permanece restrito a 1..2000 no código testado. O RSS medido permaneceu baixo e cresceu modestamente, mas não permite concluir memória constante para milhões de estudantes.

## Estado do teste geral e próximos gates

O teste geral anteriormente informado após PR #55 executou 14 testes Rust, todos verdes, e paridade JSONL com duas seeds (2.606 linhas cada), porém o Python local apresentou **96 passed, 3 failed** em LUPA (uso de scorer do sklearn com `pos_label=1` e classes textuais). O PR #56 modifica o scorer da LUPA e **já foi integrado à develop**, conforme verificação de código. Ainda é necessário **reexecutar o pytest completo local após o pull** e registrar a evidência; não declarar 99/99 passados antes da execução.

Próximos passos:

1. Executar `python -m pytest -q tests/test_lupa.py` e `python -m pytest -q` no Windows Python 3.13; analisar os warnings, principalmente features inteiramente ausentes e falta de convergência MLP.
2. Compartilhar os três `benchmark.json` (500, 1000, 2000) para análise dos bytes Parquet e dos demais metadados, além do código de versão de hardware/software.
3. Adicionar perfil de CPU/tempo por fase, instrumentar conversão `serde_json::Value` → arrays Arrow e testar structs tipadas; não pressupor que remover o JSON restante fornecerá ganho proporcional.
4. Comparar Parquet com codec, dicionário e row groups equiparados e medir leitura, não apenas escrita.
5. Manter Python v3 como referência de paridade; Rust é o motor prioritário do projeto no cenário observado, não prova universal de superioridade.
6. Planejar expansão para além de 2.000 estudantes **apenas depois** de implementar e testar limite seguro, row-group bounded memory, validação de integridade e datasets maiores.

**Limitação científica:** dados sintéticos não demonstram validade educacional externa nem capacidade preditiva real de MAPA/LUPA.
