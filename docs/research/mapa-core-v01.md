# MAPA Core v0.1 — classification research baseline

**Status:** synthetic-only, offline Python; three-class classification is NOT validated in real schools.

MAPA (família de modelos) consumes the Student Timeline from GENESIS v2. M1/M2/M3 remain historical references, NOT fixed versions of MAPA. This code does not reproduce the TGI I experiments.

## Run

```bash
python -m epa.genesis.v2 --output data/mapa-demo --students 100 --seed 20261029
python -m epa.core_engine.mapa --dataset data/mapa-demo --seed 20261029 --output data/mapa-demo-report.json
pytest -q
```

Output report `epa.mapa.benchmark.v1` includes N1/Early, N2/Trajectory and N3/Consolidated study blocks. For each, compares majority control, logistic regression and 200-tree Random Forest with grouped-by-student holdout. Models are fitted only on the training portion. F1 macro, balanced accuracy, accuracy, recalls per class, confusion matrices, and actual class counts are recorded.

The **features** are strictly from the time-available snapshot: current N1..cutoff grades and attendance, and prior academic years' same-subject history, not final results. Target only is year-end final subject average: approved >= 6, recovery >= 4 and < 6, failed < 4 (illustrative synthetic labeling, not school policy). Preprocessing (imputation and standardization) is fitted inside each training pipeline.

## Limitations / blockers

- Dataset generated by simplified synthetic rules: benchmark results do not prove efficacy in real cohorts.
- Split ensures distinct students in training and test but same subjects and school years can appear across groups. Temporal held-out validation and cross-validation are pending.
- If a class is rare or missing, results explicitly show counts; macro F1 gives absent classes zero weight via explicit zero scores, not hidden.
- No MLflow or persisted trained model artifacts yet; no UI/worker integration. The v1 Rails task is unchanged.
- Before promoting models to a main champion, audit original M3 evidence, externally validate class definitions, temporal prediction protocol and outcome balance.
